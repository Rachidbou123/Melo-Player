# Melo

A clean, offline-first music player built for everyday listening.

### Features

* Local music library (MP3, FLAC, WAV, M4A, AAC, OGG)
* Custom playlists (create, rename, reorder, delete)
* Favorites and listening history
* Queue management with reordering
* Instant multi-field search
* System background playback & lock screen media controls
* Android system media controls & Bluetooth headset integration
* Hardware Equalizer presets & Bass Boost
* Dual-engine audio crossfade (1–12 seconds)
* Offline local playback
* Smart rule-based playlists
* Natural language local AI playlist generator
* Voice commands
* Real-time audio visualizers
* Local backup and restore (JSON export/import)
* Modern dark & light themes

### Installation

1. Open the GitHub Releases page.
2. Download the latest `Melo-v1.0.0.apk`.
3. Install the APK on your Android device (Android 7.0+ / API 24+).
4. Allow Android's installation permission if required.
5. Open Melo and scan your storage to import your local audio files.

### Important

Melo is an independent, fan-made local music player designed for playing audio files stored on your device. Melo is not affiliated with, endorsed by, or sponsored by Spotify, YouTube Music, Apple Music, or other commercial streaming services.
